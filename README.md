# Desafios de Programação

Repositório com projetos e desafios de programação em JavaScript. Cada projeto é uma aplicação web funcional com HTML, CSS e JavaScript.

---

## 📋 Projetos

### 001 - Calculadora de IMC

**Descrição:** Aplicação que calcula o Índice de Massa Corporal (IMC) e fornece uma classificação de peso baseada nos critérios da OMS.

**Funcionalidades:**

- Entrada de nome, peso (kg) e altura (m)
- Cálculo automático do IMC
- Classificação do resultado (Abaixo do peso, Peso normal, Sobrepeso, Obesidade grau 1/2/3)
- Validação de campos obrigatórios

**Tecnologias:** HTML5, CSS3, JavaScript (vanilla)

**Localização:** `001 imc/`

---

### 002 - Calculadora

**Descrição:** Calculadora web completa com interface inspirada em calculadoras clássicas, suportando as operações matemáticas básicas.

**Funcionalidades:**

- Operações: adição, subtração, multiplicação e divisão
- Botões de limpeza (CE/C) e backspace
- Suporte a números decimais
- Alternância de sinal (±)
- Display em tempo real

**Tecnologias:** HTML5, CSS3, JavaScript (vanilla)

**Localização:** `002 calculadora/`

## 🚀 Como Usar

1. Clone ou baixe o repositório
2. Navegue até a pasta do projeto desejado
3. Abra o arquivo `index.html` em seu navegador

Exemplo:

```bash
cd 001\ imc
# Abra index.html no navegador
```

```

```
